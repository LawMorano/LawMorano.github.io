# FTC team website

A free, responsive team website designed for GitHub Pages.

## Customize it

The team name, number, story, competition history, photos, Instagram, mailing
list, and join form are already included. Update the robot details and replace
the sponsor placeholders as the season develops.

Edit colors at the top of `styles.css`. Add team images in an `images` folder and reference them from `index.html`.

## Publish with GitHub Pages

1. Push these files to a public GitHub repository.
2. Open **Settings → Pages** in that repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The site will be available at `https://USERNAME.github.io/REPOSITORY/`. For the shorter `https://USERNAME.github.io/` address, name the repository exactly `USERNAME.github.io`.
